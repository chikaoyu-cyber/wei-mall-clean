# 部署与启动说明

## 0. 前置条件

| 项 | 说明 |
| --- | --- |
| 虚拟机 | CentOS 7 + Docker，IP 记为 `<VM_IP>` |
| 本机 | JDK 17（Sentinel Dashboard 用）、IDEA、nginx（用仓库里的 `frontend/hmall-nginx/`） |
| 网络 | 本机与 VM 走 NAT / VMnet8，需能互相访问 |

**第一步永远是替换 IP**：全仓库 17 处 `192.168.197.129`，换成 `<VM_IP>`。

```bash
grep -rl 192.168.197.129 . | xargs sed -i 's/192.168.197.129/<VM_IP>/g'
```

---

## 1. 四个容器

把 `deploy/` 上传到 VM 后，按下列要点创建容器（具体 `docker run` 参数按镜像版本与挂载路径调整）：

| 容器 | 端口 | 挂载 / 配置来源 | 备注 |
| --- | --- | --- | --- |
| MySQL | 3306 | `deploy/mysql/conf/hm.cnf`、`deploy/mysql/init/hmall.sql` | `init/` 下的 SQL 只在首次创建数据卷时自动执行 |
| Nacos | 8848 | `deploy/nacos/custom.env` | standalone 模式，外挂 MySQL 库 `nacos` |
| RabbitMQ | 5672 / 15672 | `deploy/rabbitmq/*.ez` | 把插件放进容器的 plugins 目录并 `rabbitmq-plugins enable rabbitmq_delayed_message_exchange` |
| Seata TC | 7099（控制台）/ 8099（服务） | `deploy/seata/` | 控制台 7099 / 服务 8099，请按此端口配置 |

---

## 2. 建库与配置导入（顺序不能乱）

1. 导入 `deploy/sql/nacos.sql`、`deploy/sql/seata-tc.sql` → 建 Nacos、Seata 元数据库。
2. 导入分库脚本：`hm-item.sql`、`hm-cart.sql`、`hm-user.sql`、`hm-trade.sql`、`hm-pay.sql`。
3. 单体版（可选）导入 `deploy/mysql/init/hmall.sql`。
4. **导入 Nacos 配置**：`deploy/nacos/config/` 下 6 个文件，按文件名作为 dataId、分组 `DEFAULT_GROUP` 导入：

   | dataId | 作用 |
   | --- | --- |
   | `shared-jdbc.yaml` | 各服务数据库连接（支持 `hm.db.host` / `hm.db.pw` 环境变量覆盖） |
   | `shared-seata.yaml` | Seata TC 注册与事务组映射 |
   | `shared-log.yaml` | 日志级别 |
   | `shared-swagger.yaml` | 接口文档 |
   | `gateway-routes.json` | 网关路由规则 |
   | `cart-service.yaml` | 购物车容量限制 |

   Nacos 控制台「配置管理 → 导入配置」可批量导入 zip；也可直接写入 `nacos.config_info` 表。
   `deploy/nacos/config/_index.json` 是导出清单，仅供核对，不需要导入。

---

## 3. 启动顺序

1. VM：4 个容器起来，确认端口都通。
2. 本机：启动 nginx（门户 `http://localhost:18080/`）。
3. IDEA 打开 `backend/hmall`，依次启动：

   | 顺序 | 启动类 | 端口 |
   | --- | --- | --- |
   | 1 | ItemApplication | 8081 |
   | 2 | CartApplication | 8082 |
   | 3 | UserApplication | 8084 |
   | 4 | TradeApplication | 8085 |
   | 5 | PayApplication | 8086 |
   | 6 | GetewayApplication | 8080 |
   | 可选 | ItemApplication 2（多实例 / 负载均衡演示） | 8083 |
   | 可选 | HMallApplication（单体版） | 8087 |

4. 可选：Sentinel Dashboard
   `java -Dserver.port=8090 -jar sentinel-dashboard-1.8.6.jar` → `localhost:8090`，账号密码 sentinel / sentinel。

---

## 4. 验证清单

- `http://localhost:18080/` 打开微商城首页 → 点「去购物」能看到商品列表。
- 登录（jack / 123）→ 顶栏显示用户名与退出登录。
- 商品页「立刻购买」→ 结算页显示 1 件商品、地址与金额。
- 购物车 → 确认订单 → 余额支付 → 支付成功 → 我的订单能看到状态。
- Nacos 控制台服务列表应有 6 个微服务；Seata 控制台 7099 可打开。

## 5. 已知说明

- **消息链路**：业务代码直接注入 `RabbitTemplate`，下单时发送延迟消息，超时未支付自动取消订单。
- **Sentinel Dashboard 是可选监控 UI**：客户端 SDK 内嵌在各 Java 进程里，不启动 Dashboard 不影响限流规则生效（只是看不到界面）。
- 配置里的口令是示例默认值，仅用于内网演示。
